# QuickLex 0.3.0 验证记录

日期：2026-10-14。安装目标：Zotero 10.0.x，实际 Windows 客户端 10.0.6。

## 词库与释义来源

- 英文 ECDICT：399,213 个词条、56,954 个词形索引键，常用词预载 8,000 个。
- 俄汉释义更换为 БРуКС / BKRS.info 2026-10-14 DSL 快照：122,937 个有中文释义的单词 / 连字符词，1,505,408 个词形索引键。词条数不包括一般多词短语。
- 保留中文义项、拼音、用法和例句；不再附维基词典来源或将新词库标为 CC BY-SA。BKRS 原始自由使用声明随 XPI 附带，OpenCorpora 形态索引的原始与转换许可分别保留。
- 原始 DSL 与 gzip 均做固定 SHA-256 校验。词形扩展只使用匹配原形的明确 OpenCorpora 范式，不进行预测或生成中文释义。
- Python 构建器与 JavaScript 导入器对完整 БРуКС 输入导入相同数量的词条，抽样文章逐字一致。

## Windows 原生客户端

在工作区内创建独立测试配置和空文献库，仅加载发行 XPI 与测试伴随插件；不使用或修改个人 Zotero 配置。

Windows Zotero 10.0.6 已验证：

1. XPI 激活、兼容性、0.3.0 版本和工具菜单。
2. 使用已注册阅读器回调和真实 DOM 显示 `novel`、`НАУ́КА`、`исследования`、`ученый`、`статистические`、`читает`、`экономического`、`церковной`。
3. 俄语卡片标明 БРуКС，中文义项、拼音和例句进入渲染结果。
4. 使用实际 IOUtils 将测试 DSL 转换为本地分片，以自备释义查 `статистические`。
5. 停用并重新启用插件，阅读器恢复导入词典，显示自备释义和名称。
6. 触发真实“恢复内置俄汉词典”菜单命令，卡片重新显示 БРуКС。
7. 文件选择器模块可加载；原生检查不操纵系统文件选择对话框。

## 性能与限制

[0.3.0 Node 基准](benchmark-0.3.0.json)：内置俄汉词库空插件缓存的 13 个查询中位数 3.337 ms、P95 6.041 ms。仅统计 Node 文件读取与查询，不包含 XPI 解压、Zotero 原生弹窗等待、DOM 绘制；也不是其他插件的对比测试。自备词典的速度受词库大小、磁盘及命中情况影响。

此检查不能代替真实 PDF 双击、各阅读器窗口与其他插件共存的体验测试。俄汉词库不提供 IPA；自备 DSL 的新词如果不在内置形态索引中，需查询原形。加密词典、MDX / LSD / StarDict / 压缩包和整句翻译不在本版导入范围内。释义错误、漏词和复杂 DSL 排版仍可能需要按具体样例改进。
