# QuickLex 0.3.1 · 常规英汉版

**默认 `main` 分支恢复为仅英汉查词。** 俄汉查词、俄语词形还原及 DSL 词典导入完整保留在独立的 [`russian` 分支](https://github.com/vbcnft59/zotero-quicklex/tree/russian)，需要俄语的用户可继续下载 [v0.3.0](https://github.com/vbcnft59/zotero-quicklex/releases/tag/v0.3.0)。

- 常规版仅内置 ECDICT，包含 399,213 个英汉词条、音标、多义项、英文释义及词形还原。自动查词继续离线，无需 API Key。
- 不打包俄语代码、词库、形态数据和 DSL 导入模块，安装包约 **21 MB**。切换分支后本地残留的俄语构建文件也会排除。
- Windows、Intel Mac 和 Apple Silicon Mac 保留支持，使用同一个 **`quicklex-0.3.1.xpi`**，要求 Zotero 10.0.x。
- 两个分支使用同一插件 ID，安装另一版会切换版本；常规版不读取或删除俄语版已保存的自备词典。
- 21 项 JavaScript 测试及实际英汉发行包检查通过；Windows Zotero 10.0.6 独立配置已验证启用、5 个真实 DOM 查词、英汉菜单及忽略俄文选词。两种 Mac 架构执行相同原生检查，见 GitHub Actions 附件。

安装：**Zotero → 工具 → 插件 → 齿轮 → 从文件安装**，选择 **`quicklex-0.3.1.xpi`**，无需解压。已有旧版或俄语版可直接安装，必要时重启。

附件：`.xpi` 是安装包，`.sha256` 为校验文件，`quicklex-0.3.1-source.zip` 为源码。普通用户只需 XPI。此版继续手动安装 XPI 更新。

---

English: The default `main` branch now contains only the regular English–Chinese edition, bundling ECDICT with 399,213 entries and preserving pronunciation, multiple senses, English definitions, inflections, and offline lookup. Russian–Chinese lookup and DSL import remain on the separate `russian` branch and in release v0.3.0. The regular XPI excludes Russian modules and data, including cached build outputs, reducing its size to about 21 MiB. Windows, Intel Mac, and Apple Silicon Mac use the same XPI on Zotero 10.0.x. Both editions share an add-on ID; installing one switches editions. Imported Russian dictionary files remain untouched. Download the XPI to install.
