# QuickLex 速查 0.1.1 · 初始公开试用版

Zotero 10 的英汉离线查词插件，优先减少选词后等待在线翻译服务的时间。

## 下载与安装

在本页 **Assets** 下载 **`quicklex-0.1.1.xpi`**，无需解压。

Zotero → 工具 → 插件 → 齿轮 → 从文件安装插件，选择 XPI。GitHub 自动生成的 Source code 压缩包用于开发，不能直接安装。

## 功能

- 随包安装 399,213 个英汉词条，无需 API Key，自动查词无需联网。
- 8,000 个常用词预加载、分片按需读取与内存缓存。
- 中文多义项、音标、可展开的英文释义及常见词形还原。
- 单词查询入口和手动在线补查。
- 修复 0.1.0 因缺少必需清单字段而无法安装的问题。

## 验证与限制

已在 Windows / Zotero 10.0.6 的独立配置中验证启用、工具菜单和手动查词；19 项自动化测试通过。PDF 阅读器的双击选词弹窗仍待完整实机验证，其他系统和 Zotero 版本尚未验证。本次标记为试用版，欢迎通过 Issues 反馈问题。

此版本通过下载新的 XPI 手动更新，未提供自动更新服务。词典释义受 ECDICT 数据覆盖和质量限制，不会依据论文上下文自动选择义项。

## 来源与许可

插件源码采用 MIT 许可。词库来自 MIT 许可的 ECDICT，完整来源和许可证随 XPI 分发，详情见仓库 THIRD_PARTY_NOTICES.md。
