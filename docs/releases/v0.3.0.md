# QuickLex 0.3.0 · 更换俄汉词典，支持离线 DSL 导入

俄汉释义已从维基词典更换为 **БРуКС / BKRS.info**，保留中文义项、拼音、用法及例句。内置 **122,937 个俄汉单词词条**，配合 **1,505,408 个明确词形索引键**，继续支持 `статистические`、`читает` 等变形查询。英文仍使用 ECDICT，自动查词继续离线，无需 API Key。

- 新增 **工具 → QuickLex 速查 → 导入俄汉词典（DSL）…**。支持解压后的 UTF-8 / 带 BOM 的 UTF-16 `.dsl` 文本，最大 128 MiB；导入时无需 Python。
- 优先显示导入词典的释义，缺词时使用内置 БРуКС；卡片标明实际来源。导入结果以本地分片保存，重启后恢复。
- 可通过 **恢复内置俄汉词典** 撤回导入。导入失败保留现有词典。导入文件不被修改、不上传，也不会加入公开发布包。
- 自备词典的变形复用内置索引已有的明确关系；新词不在索引时需查询原形。本版不直接导入 MDX、LSD、StarDict、压缩包或加密词典。
- 保留 БРуКС 的来源与自由使用声明，独立保留 OpenCorpora 形态索引许可。该俄汉词库不提供 IPA 音标。
- 34 项 JavaScript 和 5 项 Python 测试通过；Windows Zotero 10.0.6 独立配置中验证加载、8 个真实 DOM 查词、DSL 导入、插件重启后恢复及切回内置词典。两种 Mac 架构由 GitHub Actions 执行相同原生检查，报告见任务附件。

Windows、Intel Mac 和 Apple Silicon Mac 使用同一个 **`quicklex-0.3.0.xpi`**，要求 Zotero 10.0.x。安装：**Zotero → 工具 → 插件 → 齿轮 → 从文件安装**，选中 XPI，无需解压。已有旧版可直接安装新版，必要时重启。

附件中 `.xpi` 是安装包；`.sha256` 是校验；`quicklex-0.3.0-source.zip` 是源码；`dabruks_261014.gz` 是用于可复现构建的原始词库。**普通用户只需下载 XPI，内置词典已可离线使用。**

释义准确性仍取决于原词库。程序触发阅读器回调不等同于完整 PDF 交互测试。本版继续手动安装新 XPI 更新。

English: Russian–Chinese definitions now use БРуКС / BKRS.info instead of Wiktionary, with 122,937 single-word articles, Chinese senses, pinyin, examples, and 1,505,408 form-index keys. Adds optional local DSL import (UTF-8 or BOM UTF-16, uncompressed, up to 128 MiB), priority for imported definitions, bundled fallback, persistence after restart, and a restore command. Imports remain local. New headwords absent from the bundled form index require exact-headword lookup. Same XPI for Windows, Intel Mac, and Apple Silicon Mac with Zotero 10.0.x. Download the XPI to install; other assets are for developers. English lookup remains available. Full attribution and dictionary permissions are included.
