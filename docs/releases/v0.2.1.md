# QuickLex 0.2.1 · 扩充俄汉词库与词形覆盖

修复 0.2.0 大量俄语单词无法查到的问题，尤其是 `статистические` 这类形容词变形。Windows、Intel Mac 和 Apple Silicon Mac 继续使用同一个 **`quicklex-0.2.1.xpi`**，要求 Zotero 10.0.x。

- 俄汉词条 **17,383 → 95,604**，约为原来的 **5.5 倍**。补齐此前漏收的上游“俄语”数据分区，与“俄語”分区按 `lang_code=ru` 合并。
- 词形索引 **71,489 → 1,373,925** 个键。新增 OpenCorpora 显式范式，覆盖更多形容词变格、动词变位和名词变格，无需运行时猜词。
- 已验证 `статистические`、`статистическими`、`читает`、`читают`、`экономического`、`церковной`、`официальные`、`содержали`、`которые`、`сведения`、`словами` 等此前漏查的词。
- 俄语改为 1,024 个小分片，按需读取并缓存；英文词库和加载方式保留，自动查词继续离线，无需 API Key、Python 或其他外部程序。
- 新增词形歧义、来源分区、形容词和动词等回归测试：27 项 JavaScript 测试、5 项 Python 测试。

安装：Zotero → 工具 → 插件 → 齿轮 → 从文件安装，选择 XPI，无需解压。已有旧版可直接安装新版，必要时重启。截图中的 `статистические` 现在可还原到 `статистический`，显示“统计的 / 统计学的”。

释义来自中文维基词典，部分为繁体；覆盖和准确性仍受原始数据限制。形态数据来自 OpenCorpora（原始 CC BY-SA 3.0），转换后的俄语组合数据以 CC BY-SA 4.0 分发，附完整来源及许可。插件代码与 ECDICT 仍采用 MIT。此版继续手动安装 XPI 更新。

附件：`.xpi` 是安装包；`.sha256` 为校验文件；`quicklex-0.2.1-source.zip` 为源码；`ru-zh-wiktionary-simplified-20261001.jsonl.gz` 为新增词库的固定输入快照。普通用户只需 XPI。

---

English: Expands Russian–Chinese headwords from 17,383 to 95,604 and form-index keys from 71,489 to 1,373,925. Imports both Russian language-name partitions and explicit OpenCorpora paradigms, fixing missing forms such as `статистические`, `читает`, and `экономического`. Uses 1,024 on-demand Russian shards with caching; no Python or analyzer is needed at runtime. Same XPI for Windows, Intel Mac, and Apple Silicon Mac on Zotero 10.0.x. Original data licensing and attribution are included. Coverage remains limited by the sources.
