# QuickLex 0.2.0 · macOS 与俄汉离线查词

Windows、Intel Mac 和 Apple Silicon Mac 安装同一个 **`quicklex-0.2.0.xpi`**。要求 Zotero 10.0.x，通过“工具 → 插件 → 齿轮 → 从文件安装插件”安装，无需解压。旧版用户直接安装新版，必要时重启 Zotero。

- 新增 **俄语单词 → 中文释义**，保留英文查词，自动识别语言。
- 内置 17,383 个俄汉词条及 71,489 个词形索引键，支持词库已有的变格、变位、重音及省略 ё 的写法；例如 `НАУ́КА`、`исследования`、`методы`、`идёт`。
- 俄语按需读取小分片，两种语言缓存独立；英文使用时不加载俄语数据。自动查词无需网络或 API Key。
- 俄语释义来自中文维基词典，经 Kaikki/Wiktextract 提取，独立按 CC BY-SA 4.0 分发，附署名、来源及许可；部分中文为繁体，覆盖有限。
- 补充 macOS 安装说明、中文默认 / 英文 README 和跨平台构建、原生客户端检查。

本地 25 项 JavaScript 测试和 1 项 Python 数据转换测试通过，Windows Zotero 10.0.6 隔离配置中的实际加载、释义渲染通过。Apple Silicon / Intel Mac 原生检查结果见对应 [Actions](https://github.com/vbcnft59/zotero-quicklex/actions)。程序触发选词回调不能代替实际 PDF 双击体验验证。

此版仍通过安装新 XPI 手动更新。仅支持单词查询，不提供整句翻译或 OCR。

**附件**：`.xpi` 为安装包，`.xpi.sha256` 为校验文件，`quicklex-0.2.0-source.zip` 为源码，`ru-zh-wiktionary-20261001.jsonl.gz` 为重现构建所需的 CC BY-SA 4.0 数据快照。普通用户只需 XPI。

English: Adds offline Russian → Chinese while retaining English → Chinese, automatic language detection, 17,383 Russian headwords and 71,489 form-index keys. Supports recorded inflections, stress marks, and omitted ё. Windows and both Mac architectures use the same XPI for Zotero 10.0.x. Chinese Wiktionary text is separately CC BY-SA 4.0; some glosses use traditional Chinese and coverage is limited. See README.en.md and Actions for validation. Install the `.xpi` through Zotero; source/data archives are for development.
